## Design Context

### Users
Small household (1–2 people). Primary user is technically savvy and built the app themselves; a second user (partner/family member) may be less technical. The core job: track spending, manage envelope budgets, and feel genuinely in control of household finances. Used regularly — daily or weekly — not just in moments of crisis.

### Brand Personality
**Three words: Steady. Clear. Trustworthy.**

Financial data is inherently stressful. IGAB should feel like a well-designed tool you can rely on — not a product trying to impress you. Confidence comes from clarity, not visual flourish. The tone is composed and professional without being cold or corporate.

### Aesthetic Direction
**Refined functional** — the aesthetic of a craftsperson's tool. Beautiful because it works, not because it decorates.

- Honors each theme's personality (Catppuccin, Rosé Pine, Nord, Gruvbox are all loved for their intentionality — the app should respect that)
- Muted, purposeful color — accent color reserved for meaningful state, not decoration
- Information density is a feature, not a problem to solve away
- Typography should be elevated beyond system defaults — the app deserves custom fonts that signal care

**References**: Well-designed accounting tools, terminal apps that take aesthetics seriously, productivity tools like Linear or Things 3 (calm, dense, deliberate).

**Anti-references**:
- No flashy fintech (Robinhood, Revolut) — no gradient text, glowing metrics, neon-on-dark
- No generic SaaS (Stripe-clone card grids, hero metric layouts, Inter + rounded corners everywhere)
- No corporate/enterprise dashboard (gray Excel lookalike, stuffy table-heavy layouts)

### Design Principles
1. **Meaning over decoration** — every visual element earns its place by carrying information or guiding attention. No sparklines for decoration, no gradient fills that don't encode data.
2. **Calm by default** — restrained palette with color reserved for genuine state changes (overspent, funded, warning). The resting state of the UI should be quiet.
3. **Theme integrity** — each of the 7 themes should feel like it was designed for that palette, not just variable-swapped. Honor the source material.
4. **Trust through consistency** — interactions behave predictably. Form elements, hover states, and navigation patterns are uniform throughout. No surprises.
5. **Accessible without fuss** — best-effort WCAG AA: proper contrast ratios, keyboard navigation, clear focus indicators. Fix obvious issues without over-engineering.
